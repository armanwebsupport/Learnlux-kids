# LearnLux Kids — Premium GitHub Version

## Files
- `index.html` — app structure
- `style.css` — premium responsive design
- `script.js` — learning data, navigation, quizzes, speech and local progress
- `images/` — put your real JPG/PNG/WebP learning images here

## Real images
The app already points to local image paths. Upload images using the filenames generated from the item names.

Examples:
- `images/fruits/apple.jpg`
- `images/animals/lion.jpg`
- `images/birds/peacock.jpg`
- `images/numbers/0.jpg`
- `images/countries/india.jpg`
- `images/personalities/a-p-j-abdul-kalam.jpg`

For the alphabet:
- `images/alphabet/a.jpg`
- `images/alphabet/b.jpg`
- etc.

If an image is missing, the app automatically shows a clean text fallback instead of breaking.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js` and the entire `images` folder.
3. Open Settings → Pages.
4. Select the `main` branch and `/ (root)`.
5. Save. GitHub will publish the website.

## Important
This is a premium frontend prototype. It does not include a backend, user accounts, cloud sync, payments, or a native APK build.
